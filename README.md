# montca-web

Web de **Montca Actiu**, associació juvenil i esportiva de Cocentaina.

## Arrancar en local
```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # comprobar antes de abrir un PR
```

## Cómo trabajamos
- Las tareas están en GitHub Issues y en el tablero del Project.
- Una rama por issue y todo entra por Pull Request revisado por el otro.
